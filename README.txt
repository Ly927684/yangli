个人学术主页 / Academic Homepage

查看网站：双击 index.html，右上角切换中文／English。
编辑网站：双击 editor.html，填写表单。所有编辑和图片处理都在本地浏览器完成，无需注册或联网。
主栏目管理：新增、删除、重命名、上移／下移栏目，导航自动同步。删除栏目后可在本次编辑中撤销；长期保留请先备份草稿。
论文／专利、横向项目和纵向项目可以新增、删除和排序。
修改后先预览，再点击“导出网站包”。解压导出的 ZIP，新 index.html 即是更新版本，editor.html 也会带上最新内容。
“保存草稿”存在当前浏览器；更换浏览器或清理网站数据可能丢失。请定期下载“备份草稿”，可用“导入草稿”恢复。
本地预览不会自动更新 GitHub。上线时上传 index.html、全部 portfolio-*.html、assets 文件夹和 .nojekyll；editor.html 不需要上传。
日期、作者及期刊专名按原记录显示。翻译可在中英文表单中分别修订。学院英文名称目前为暂译。
